An AI-powered Python Code Review Assistant built using **Streamlit** and **Google Gemini AI**, with the AI review logic also exposed via a standalone **FastAPI REST API**. The application automates code analysis by performing syntax validation, static analysis, security scanning, complexity analysis, AI-powered code review, AI-based refactoring, automatic PyTest generation, test execution, and professional PDF report generation, all wrapped in an interactive **Streamlit** dashboard.

## ⚡ FastAPI Integration

The AI code review logic is exposed as a lightweight **FastAPI REST API** (`api.py`), built on top of the existing `review_code()` function from `utils/ai_reviewer.py`. This lets the Gemini-powered review be triggered independently of the Streamlit UI — via `curl`, Postman, or any other client.

### Key Endpoints

| Method | Endpoint | Description |
|--------|----------|--------------|
| `GET`  | `/` | Root endpoint — confirms the API is running |
| `GET`  | `/health` | Health check endpoint |
| `POST` | `/review` | Accepts a code string and returns an AI-generated review (Gemini AI) |
| `GET`  | `/docs` | Interactive Swagger UI (auto-generated by FastAPI) |

### Run the FastAPI Server

```bash
uvicorn api:app --reload --host 0.0.0.0 --port 8000
```

Once running, visit:

- Swagger UI → `http://localhost:8000/docs`
- ReDoc → `http://localhost:8000/redoc`

### Example Request

```bash
curl -X POST "http://localhost:8000/review" \
  -H "Content-Type: application/json" \
  -d '{"code": "def add(a, b):\n    return a + b"}'
```

### Example Response

```json
{
  "review": "The function is simple and correct. Consider adding type hints and a docstring for clarity."
}
```

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Harshali2628/AI-Code-Review-Assistant.git
```

### Open Folder

```bash
cd AI-Code-Review-Assistant
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Add Gemini API Key

Create a `.env` file.

```env
GEMINI_API_KEY=YOUR_API_KEY
```

### Run the Project

Start the **FastAPI backend**:

```bash
uvicorn api:app --reload
```

In a separate terminal, start the **Streamlit frontend**:

```bash
streamlit run app.py
```

## 🐳 Docker

### Build

```bash
docker build -t ai-code-review-assistant .
```

### Run (Streamlit UI)

```bash
docker run -p 8501:8501 --env-file .env ai-code-review-assistant
```

### Run (FastAPI backend)

```bash
docker run -p 8000:8000 --env-file .env ai-code-review-assistant uvicorn api:app --host 0.0.0.0 --port 8000
```

> 💡 For local development, you can also run both services together using `docker-compose` if a `docker-compose.yml` is added to the project.

### Workflow

1. The user uploads a Python source code file through the Streamlit interface (syntax checking, static analysis, security scanning, and complexity analysis run directly within the app).
2. In parallel, the **FastAPI service** (`api.py`) exposes the Gemini-powered `review_code()` function as a standalone `/review` endpoint, so any external client can request an AI code review over HTTP.
3. Google Gemini AI generates an intelligent code review with suggestions and improvements.
4. The Streamlit app combines the static analysis results and AI review to calculate quality metrics and generate a PDF report.
5. The interactive dashboard displays the results and allows users to download the generated report.

> 📝 Currently only the `/review` endpoint is implemented in the API. The other analysis steps (syntax check, Pylint, Bandit, Radon, PDF report) run inside the Streamlit app directly. They can be exposed as additional FastAPI endpoints later — see **Future Improvements** below.
