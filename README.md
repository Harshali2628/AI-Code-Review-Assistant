An AI-powered Python Code Review Assistant built using **FastAPI**, **Streamlit**, and **Google Gemini AI**. The application automates code analysis by performing syntax validation, static analysis, security scanning, complexity analysis, AI-powered code review, AI-based refactoring, automatic PyTest generation, test execution, and professional PDF report generation — all exposed through a **FastAPI REST API** and consumed by an interactive **Streamlit** dashboard.

## ⚡ FastAPI Integration

The core analysis logic (syntax checking, static analysis, security scanning, Gemini AI review, refactoring, test generation, and PDF reports) is now exposed as a standalone **FastAPI REST API**. The Streamlit app calls these endpoints internally, so the same API can also be consumed independently — via `curl`, Postman, or any other client.

### Key Endpoints

| Method | Endpoint | Description |
|--------|----------|--------------|
| `POST` | `/analyze` | Upload a `.py` file and run syntax, static, security & complexity analysis |
| `POST` | `/review` | Get AI-generated code review & refactoring suggestions (Gemini AI) |
| `POST` | `/generate-tests` | Generate and run AI-created PyTest unit tests |
| `POST` | `/report` | Generate a downloadable PDF report of the full analysis |
| `GET`  | `/health` | Health check endpoint |
| `GET`  | `/docs` | Interactive Swagger UI (auto-generated by FastAPI) |

### Run the FastAPI Server

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Once running, visit:

- Swagger UI → `http://localhost:8000/docs`
- ReDoc → `http://localhost:8000/redoc`

### Example Request

```bash
curl -X POST "http://localhost:8000/analyze" \
  -F "file=@sample.py"
```

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Harshali2628/AI-Code-Review-Assistant.git
```

### Open Folder

```bash
cd AI-Code-Review-Assistant
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Add Gemini API Key

Create a `.env` file.

```env
GEMINI_API_KEY=YOUR_API_KEY
```

### Run the Project

Start the **FastAPI backend**:

```bash
uvicorn main:app --reload
```

In a separate terminal, start the **Streamlit frontend**:

```bash
streamlit run app.py
```

### Build

```bash

```

### Workflow

1. The user uploads a Python source code file through the Streamlit interface.
2. Streamlit sends the file to the **FastAPI backend** via a REST API request.
3. FastAPI validates the code using the syntax checker.
4. Static analysis tools (Pylint, Bandit, and Radon) evaluate code quality, security vulnerabilities, and complexity.
5. Google Gemini AI generates an intelligent code review, refactoring suggestions, and improvement recommendations.
6. FastAPI combines all analysis results, calculates quality metrics, and returns a JSON response (and/or generates a PDF report).
7. The Streamlit dashboard renders the results and allows users to download the generated report.
